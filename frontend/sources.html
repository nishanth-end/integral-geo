Sources & Data Transparency Register

Public access repository providing the original government monitoring reports, the compiled relational SQLite database, and complete schema definitions for independent audit, replication, and citizen inspection.

This projects exists to provide transparent data available to the public in a stable open-source format. The original files are in PDF format and not easily accessible for analysis or verification. I made this to make the work easier for the public, journalists, and civic activists to verify the work of NHAI and the government. The database is also useful for researchers, journalists, and policy analysts to study infrastructure development patterns, contractor performance, and project timelines. To maintain public trust, the database is released under an open license (ODbL) and the application code is released under GPL-3.0.

Source Data Attribution

The raw infrastructure project data used in this project is sourced from the publicly available Management Information System (MIS) documents published by the National Highways Authority of India (NHAI).

  • Source Authority: National Highways Authority of India (NHAI), Regional Office - Bengaluru, Karnataka.
  • Original Work: Publicly released monthly project status and monitoring reports.
  • Disclaimer: This project is an independent, open-source civic computing initiative. It is not affiliated with, endorsed by, or connected to NHAI or the Government of India. The data is provided "as-is" for informational and transparency purposes.
